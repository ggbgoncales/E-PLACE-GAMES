# Documentação do E-Place

Site de documentação feito com [Docusaurus](https://docusaurus.io/).

## Rodar localmente

```bash
npm install
npm start
```

## Gerar a versão final

```bash
npm run build
npm run serve
```

Antes de publicar, troque o valor de `url` em `docusaurus.config.js` pelo endereço real do site.
