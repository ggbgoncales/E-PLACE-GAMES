## Flappy Bird: Skyward

Jogo arcade em Python/Pygame, em tela cheia sem borda, com cenário completo.

### Instalação
pip install -r requirements.txt

### Execução
python main.py

### Controles
- Espaço, W ou seta para cima: voar
- Setas ou WASD: navegar pelos menus
- Enter ou Espaço: selecionar/comprar/equipar
- Esc: voltar / sair (no menu)
